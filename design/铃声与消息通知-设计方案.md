# 铃声 & 消息通知 — 产品重设计方案（v3）

> 视角：UI Designer（兼产品视角）。目标：在「确认后再开发」的前提下，给出可落地的重设计方案与视觉稿。
> 配套视觉稿：`mockup-settings.html`（设置面板）、`mockup-notification-center.html`（消息通知中心）、`mockup-tray-menu.html`（托盘菜单·已连接用户）。
> v3 变更：固化 3 决策点；设置面板按 5 项细化重做；新增托盘菜单已连接用户列表。

---

## 0. 一句话结论

- **铃声**：「场景 × 联系人」二维体系；每场景独立开关 + 1~2 个内置默认 + 上传个性化（存本地、可作为候选项）；联系人专属设置区分「消息提醒」与「语音提醒类（语音/视频/视频会议共用）」两类。
- **消息通知**：常驻预加载通知中心（仅此一种样式）、按会话聚合未读；显示方式可切「显示内容 / 仅数量」；提醒时长可调。
- **通用**：开机启动；通知模式改为四态（正常通知 / 静音模式 / 屏蔽聊天消息 / 勿扰模式），替代原单一勿扰开关。
- **托盘菜单**：新增「已连接用户列表」，展示已连接网页的用户。
- **系统通知**：新增「被踢下线」「网络离线」两类系统级提示，复用右下角通知中心卡片样式（与普通会话卡片视觉区分），不计入会话未读、不累加托盘红点。

---

## 1. 已确认决策点（本轮固化）

| # | 项 | 结论 |
|---|---|---|
| 1 | 通知中心位置 | 右下角（沿用现状） |
| 2 | 铃声存储与候选 | 用户上传保存到本地（`userData/ringtones/`）；候选项铃声从本地已存文件读取 + 系统默认 |
| 3 | 上传大小限制 | **不限制**（移除 2MB 上限；仅做类型校验 mp3/m4a/wav） |

---

## 2. 现状与根因（不变，见 v1）

- 铃声：单一全局文件，无类型/人维度，无设置入口。
- 消息白框：`displayToast()` 每次 `new BrowserWindow`+`loadFile`+IPC 后渲染 → 先白框；`toastQueue` 逐条 + 单窗口单条 → 空框堆积、无法聚合。

---

## 3. 方案总览（不变）

1. 窗口只建一次（通知中心 / 设置 / 来电窗口启动预加载，永不因消息 `loadFile` 重建）→ 根除白框。
2. 内容随 IPC 即时更新，收到即改 DOM。
3. 未读以「会话」为聚合单元；一个会话一张卡，未读数累加。
3b. 系统通知（被踢下线 / 网络离线）作为**独立系统卡片**渲染，不进入会话未读聚合、不累加托盘红点；被踢卡片需用户处理不自动消失，离线卡片随网络恢复自动消隐。
4. 铃声解析：`个人专属 > 场景默认 > 全局默认`，受通知模式与每场景开关约束。

## 4. 功能一：铃声 & 设置面板

### 4.1 入口
托盘右键菜单「⚙ 设置」→ 单例设置窗口。

### 4.2 设置面板结构（左侧导航 + 右侧内容）
导航：**通用 · 铃声 · 消息 · 联系人专属设置 · 关于**

- 右侧内容区不再重复页面大标题与小字描述（与左侧导航重复，已去除），直接进入设置项，减少视觉噪音。

- **通用**
  - 开机启动：开关（写入系统自启，如 Windows 注册表 / 快捷方式启动目录）。
  - **通知模式（四态，单选）**：
    | 模式 | 行为 |
    |---|---|
    | 正常通知 | 所有通知与提示音正常 |
    | 静音模式 | 仅视觉提示，关闭所有声音（通话/会议窗口仍弹，但无声） |
    | 屏蔽聊天消息 | 聊天消息通知不弹、不响；**通话 / 视频 / 视频会议类提示正常** |
    | 勿扰模式 | 全部屏蔽（不弹通知、无声音，含通话/会议） |
  - （删除原「提示音量」设置；声音开闭由上述模式与每场景开关控制）
- **铃声**（核心）
  - 顶部「**铃声总开关**」：以「🔔 响铃 / 🔕 静音」**双态切换**呈现；设为静音后所有场景与联系人铃声均不播放（仍保留视觉提示）。
  - 4 个场景行：语音通话 / 视频通话 / 视频会议 / 消息通知。
    - 每行：**双态切换「响铃 / 静音」**（替代原滑动开关，语义更直观）+ 图标 + 名称 + 当前铃声名。
    - 「提示音」触发器（显示当前值 + 展开箭头 ⌄）→ 点击展开**共用的铃声选择器**：
      - 列表按 **默认 / 内置铃声 / 我的铃声（本地）** 三组呈现；每行 = 铃声名 + 独立「▶ 试听」按钮 + 选中态对勾（✓）。
      - 列表底部一个醒目的整行按钮 **「⬆ 上传自定义铃声」**（保存本地，立即加入「我的铃声」并设为当前）。
      - 选中即生效（同步更新场景「当前铃声」文案），试听与选择解耦，不弹浮层、不遮挡。
  - 候选项来源：系统默认 + 内置默认（随包）+ 本地存储文件，三者合并展示。
- **消息**
  - **显示方式**（分段控件二选一，选中项有明确高亮态）：`显示内容`（卡片显示最新一条文字）/ `仅显示数量`（仅显示头像+名称+未读数，不显示具体文字）。
  - **消息提醒持续时长**：滑杆 3~30s，默认 8s，空闲后自动收起（未读仍保留在托盘红点）。
  - （移除原「聊天消息免打扰」分区；其能力并入通用「屏蔽聊天消息」模式）
- **联系人专属设置**（原名「联系人专属铃声」）——**无弹窗，全程面板内联操作**
  - 顶部「**+ 添加联系人**」→ 就地展开内联表单（用户 ID / 备注 → 添加），不弹窗。（已移除「从已连接用户快速添加」入口。）
  - 联系人卡片：**头行**（头像 + 名称 + 两类铃声摘要）之下，**常驻可见的双列网格**直接展示两类设置，无需点击展开：
    - 左列「消息提醒」、右列「语音提醒类（**语音 / 视频 / 视频会议共用一种**）」，各列一个复用与铃声页**相同的铃声选择器**（触发器 + 分组列表 + 试听 + 上传整行按钮）。
    - 选中即保存并同步上方摘要标签；「上传自定义铃声」选完即落盘本地、自动加入候选并设为当前。
    - **无折叠、无独立子窗口、无「保存」按钮**，全程面板内常驻操作。
- **关于**：版本号、铃声存储路径等。

### 4.3 数据模型（存于 `userData/settings.json`）
```jsonc
{
  "autoStart": true,                       // 开机启动
  "notifyMode": "normal",                  // normal | silent | blockChat | dnd
  "ringtoneEnabled": true,                 // 铃声总开关
  "ringtones": {                           // 每场景独立开关 + 文件
    "call_audio": { "enabled": true,  "file": "default" },
    "call_video": { "enabled": true,  "file": "default" },
    "meeting":    { "enabled": true,  "file": "default" },
    "message":    { "enabled": true,  "file": "default" }
  },
  "contactRingtones": {                    // 联系人两类：消息提醒 / 语音提醒类
    "u_10086": { "message": "ringtones/x1.mp3", "voice": "default" },
    "u_10010": { "message": "default",            "voice": "ringtones/x2.mp3" }
  },
  "localRingtones": [                      // 本地已上传候选项（自动维护）
    "ringtones/x1.mp3", "ringtones/x2.mp3"
  ],
  "messageNotify": {
    "display": "content",                  // content | count
    "duration": 8                          // 秒
  }
}
```
- `"default"` 指向随包 `assets/ringtone.m4a`，无需落盘。
- 上传文件落盘 `userData/ringtones/<hash>.<ext>`，并写入 `localRingtones` 供候选项展示。
- **无大小限制**（仅校验类型 mp3/m4a/wav）。

### 4.4 解析逻辑（主进程）
```
resolveRingtone(callType, callerId):
  if notifyMode == "dnd"          → return null            // 全部屏蔽
  if !ringtoneEnabled             → return null            // 总开关关
  // 通话/会议类在 silent/blockChat 下仍可响（仅 normal 有声；silent 静音）
  if notifyMode == "silent"       → return null
  sceneKey = {audio:'call_audio', video:'call_video', meeting:'meeting', message:'message'}[callType]
  if callType === 'message' && notifyMode == 'blockChat' → return null  // 屏蔽聊天消息
  // 联系人专属：语音类合并 audio/video/meeting
  if callerId && contactRingtones[callerId]:
      key = callType === 'message' ? 'message' : 'voice'
      v = contactRingtones[callerId][key]
      if v != null: return v === 'default' ? ASSET : v
  if !ringtones[sceneKey].enabled → return null            // 该场景开关关
  v = ringtones[sceneKey].file || 'default'
  return v === 'default' ? ASSET : v
```
- 来电/会议窗口：解析后 `ringtonePath` 随数据下发（沿用 preload，即时播放）。
- 消息通知：通知中心内置 `<audio>`，按场景播放（受以上约束）。

### 4.5 上传 / 候选项机制
- 设置页 `<input type="file" accept="audio/*">` → 读文件 → IPC `save-ringtone` → 主进程校验类型、落盘 `userData/ringtones/` → 回写相对路径、更新 `localRingtones` → 回传前端。
- 铃声选择器候选项 = `[系统默认, 内置默认…, ...localRingtones]`（本地文件排在「我的铃声（本地）」分组）。
- **无大小限制**。

### 4.6 托盘菜单（新增已连接用户）
右键托盘菜单结构（见 `mockup-tray-menu.html`）：

┌ 我的日志 · 通知助手
├ ── 已连接用户 ──
│   张三（在线）        ← 来自已连接网页
│   李四（在线）

│   + 连接新用户
├ ───────────────

## 5. 功能二：消息通知中心（唯一样式，不变）

- 常驻预加载窗口 + `unreadMap`（按会话聚合）。
- 新消息 → 更新/置顶卡片；`display==='count'` 时不渲染消息文字。
- `notifyMode==='blockChat'` 或 `dnd` 时消息不弹、不响，仅累加托盘红点。
- 空闲 `duration` 秒自动收起；点击卡片打开会话并清除未读；「全部已读」清空。
- 视觉稿：`mockup-notification-center.html`（含「显示内容 / 仅数量」演示开关）。

## 5.1 系统通知（被踢下线 / 网络离线）

两类提示为**系统级**，不属于聊天会话，复用右下角通知中心窗口与卡片样式，但视觉上与普通会话卡区分（警示色 + 图标 + 操作按钮）。**不计入会话未读聚合、不累加托盘红点**。

### 5.1.1 被踢下线（KICKED）
- **触发**：同一账号在另一设备/网页登录，服务端令当前连接失效 → 主进程收到 `KICKED` 事件（携带踢出方设备/IP、时间）。
- **卡片**：红色警示样式，标题「您已在其他设备登录」，正文「您的账号于 <时间> 在 <设备/IP> 登录，当前会话已结束」。
- **操作**：「重新登录」（触发重连 / 打开登录页）、「知道了」（关闭卡片；在线状态由网页侧判定）。
- **行为**：需用户处理，**不自动消失**（`sticky:true`，最长停留 60s 后收起但仍留入口）；提示音复用「消息通知」场景铃声（受总开关与场景开关约束）。
- **属性**：安全相关强制提示，本期**不提供关闭开关**。

### 5.1.2 网络离线（NET_OFFLINE / NET_ONLINE）
- **触发**：主进程/前端检测到长连接断开且网络不可用 → `NET_OFFLINE`；恢复 → `NET_ONLINE`。
- **卡片**：黄色状态样式，标题「网络已断开」，正文「消息可能无法实时接收，正在尝试重连…」；可选「重试」按钮。
- **自动行为**：收到 `NET_ONLINE` 后内容切换为绿色「网络已恢复」，**3s 后自动消失**；用户也可手动关闭。
- **无声**：状态提示，默认**不播放铃声**（避免与聊天/通话抢提示）。
- **设置开关**：本期默认开启，不进「消息」分区（后续如需「网络状态提示」开关可补）。

### 5.1.3 渲染与数据
- 通知中心维护独立 `sysAlerts` 数组；系统卡片置顶于会话列表上方，用分隔标题「系统通知」与普通卡片区分。
- `sysAlerts` 项：`{ id, type:'kick'|'offline', sticky, autoDismissOn }`；被踢 `sticky:true`，离线 `autoDismissOn:'NET_ONLINE'`。
- 被踢可带 `ringtone:'message'`（复用消息通知铃声）；离线 `ringtone:null`。

## 6. 实施阶段概览（确认后开发）
1. 主进程：设置窗口单例 + 右键入口 + 已连接用户维护 + `resolveRingtone` + `settings.json` 读写 + IPC。
2. 预加载桥。
3. 设置面板 UI（`settings-window.html`）：通用(开机启动+4模式) / 铃声(总开关+每场景开关+共用铃声选择器+上传) / 消息(显示方式+时长) / 联系人专属设置(共用铃声选择器+内联添加)。
4. 通知中心 UI（`notification-center.html`）：聚合列表（支持仅数量）+ 已读 + 音频。
5. 托盘菜单（`mockup-tray-menu.html`）：已连接用户列表。
6. 改造 `SHOW_MESSAGE_NOTIFICATION`（补 `conversationId`）；新增 `USER_CONNECTED` 上报。
7. 系统通知：主进程监听 `KICKED` / `NET_OFFLINE` / `NET_ONLINE`，渲染系统卡片（被踢强制不自动消失、离线恢复后自动消隐）；被踢复用「消息通知」铃声。
8. 联调、打包验证（asar 外落盘铃声、自启写入）。
