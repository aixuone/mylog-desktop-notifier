**背景**：用户希望主页面窗口跟设置/诊断/工作台窗口一样，使用系统默认标题栏（最小化/最大化/关闭由 OS 提供），统一风格。

**改动**（`main.js` → `openMainPage()` BrowserWindow 配置，line 1599-1616）：

- 新增 `title: 'e日志'`

**保留（兼容性）**：
- close 拦截 → hide：frame:true 时系统标题栏的关闭按钮触发 close 事件，仍被拦截为隐藏到托盘（`isQuitting` 才真退）。

- `splash.html`：用 `html, body { height: 100% }` + flexbox 居中，frame:true 后 splash 显示在系统标题栏下方的内容区，无需调整。
- `webPreferences`：`backgroundThrottling: false`、`v8CacheOptions: 'bypassHeatCheck'`（首开提速）保留。
- `backgroundColor: '#F5F6F8'` 保留（content 区底色）。
