# 2026-08-22 工作日志

## 自绘标题栏改为「与主窗口一体」（in-page 注入，非独立子窗口）
- **根因**：此前标题栏是独立的子 BrowserWindow（`titlebarWindow`，`setParentWindow` 拼在主窗口上方）。
  它是第二个 Win32 窗口，存在可见缝隙，且与远程页自带的 `.top-bar`（sticky, 64px）叠加——
  38px 自绘栏只盖住远程顶栏上半部，下半 26px 仍露出，导致「不像一体 / 双栏」。
- **修复**：彻底去掉 `titlebarWindow` 及 `createTitlebarWindow / syncTitlebarToMainPage / syncMainPageToTitlebar / _titlebarDragSync`。
  改为把标题栏注入**主窗口页面自身 DOM**（真正的同一个窗口）：
  - 新增 `src/titlebar-inpage.js`（IIFE：构建 DOM + 事件绑定 + MutationObserver 防 SPA 误删 + 暴露 `window.__myTitlebar`）。
  - main.js 新增 `TITLEBAR_CSS`（经 `webContents.insertCSS` 注入，规避远程页 CSP）+ `injectTitlebar()`（insertCSS + executeJavaScript 注入 JS）+ `hideInpageTitlebar/showInpageTitlebar`（全屏隐藏）。
  - `did-finish-load`（重置 `_titlebarCssReady` 后注入）与 `did-navigate-in-page`（跳过重复 insertCSS）触发；`file://` 加载页（splash/错误页）跳过，避免标题栏闪现。
  - CSS 关键：`.top-bar { display:none!important }`（隐藏远程自带顶栏）+ `html { padding-top: 38px }`（内容下移给标题栏让位，等同系统标题栏 client area）+ `.my-titlebar{position:fixed;...;-webkit-app-region:drag}`。`html.tb-hidden` 全屏时去掉 padding。
  - `pushTitlebarStatus/User/Approval` 改为向 `mainPageWindow.webContents.send`（原向 `titlebarWindow`）。
  - 窗口控制/快捷操作/头像菜单仍走 `electronAPI.titlebarWin/titlebarQuickAction/titlebarMenu`（preload 已有）。
- **已删**：`src/titlebar-window.html`（被 in-page 方案取代）。
- **验证**：`node --check main.js` 与 `titlebar-inpage.js` 均通过；视觉一体需实际运行桌面端确认（无显示器，未实跑）。
- **取舍**：最大化态标题栏**常驻**（不再像旧方案隐藏），维持一体感；若个别页面因 `height:100vh` 字面量出现底部 38px 截断，可改 in-flow 注入。

## 标题栏：修复「恒定 x/y 双滚动条」+「窗口拖不动」
- **双滚动条根因（连锁）**：网页全局样式（layout.vue 非 scoped `<style>`，约 1829 行）`#app{width:100vw;height:100vh;overflow:hidden}`。`100vh` 无视注入的 `html{padding-top:38px}` → 文档恒多 38px → html 层 y 滚动条；y 滚动条（8px）又使 `100vw` 比可见宽多 8px → x 滚动条。
- **修复（TITLEBAR_CSS 内）**：`#app{width:100%!important;height:calc(100vh-38px)!important}` + `html.tb-hidden #app{width:100vw!important;height:100vh!important}`（全屏隐藏标题栏时还原整视口）。
- **拖不动的根因**：no-drag 规则误加在 `.tb-left/.tb-mid/.tb-winctrl` 三个横向铺满整条的容器上（`.tb-mid` 是 flex:1），整条标题栏被 no-drag 覆盖，`.tb-drag-area` 完全失效。
- **修复**：no-drag 只保留真正交互元素（`.tb-qacts,.tb-avatar-wrap,.tb-qa,.tb-search,.tb-wc,.tb-dropdown,.tb-offline`），空白处由 `.tb-drag-area`（app-region:drag）承接。⚠️ 勿回退：容器级 no-drag 会吞掉拖拽区。
- **验证**：`node --check main.js` 通过；实际拖拽/滚动条消除需桌面端运行确认。

## 标题栏：修复「底部空白一块，未占满窗口」
- **根因**：远程页 `.main-layout{height:calc(100vh - 64px)}`（layout.vue:2397）是为「上方 64px 原生顶栏」设计的。顶栏被注入 CSS `display:none` 后，它仍按 64px 扣高，比 `#app`（已收缩为 100vh-38px）矮 26px → 底部恒定空一条。
- **修复（TITLEBAR_CSS 内）**：`.main-layout{height:calc(100vh - 38px)!important}` + `html.tb-hidden .main-layout{height:100vh!important}`（全屏还原整视口）。顺带修正 agent 聊天错误提示条 `.agent-chat__error-bar` 的 `top:64px` → `44px`（全屏 12px）。
- ⚠️ 经验：隐藏远程页元素时，凡是按被隐藏元素尺寸做 `calc()` 的容器都要同步覆盖，否则留白/溢出。全局仅 `layout.vue:2397` 与 `agent-chat.css:467` 两处按 64px 计算。
- **验证**：`node --check main.js` 通过；视觉需桌面端运行确认。
