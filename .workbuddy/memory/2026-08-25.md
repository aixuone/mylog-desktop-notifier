## 托盘闪烁 Bug 修复（未读消息实时同步）
- **根因**：托盘 `unreadCount` 由 `onUnreadChange` ← `notificationCenter.syncUnread()` 的"合并聚合"驱动，易残留陈旧项 → 没有未读也一直闪。而映射网页端消息页角标的 `updateUnreadCount()` 虽已导出却**从未被 web 调用**。
- **修复**：
  - 桌面 `main.js`：`onUnreadChange` 改为 `() => {}`（托盘不再读 SYNC_UNREAD 聚合）；`UPDATE_UNREAD_COUNT` handler 仍是托盘唯一写入源。
  - web `layout.vue`：把 `updateUnreadCount` 接入 — `watch(filteredUnReadCount, …, {immediate:true})` 实时推送、并在 `onConnectionChange(online)` 重连后补齐 `updateUnreadCount(filteredUnReadCount.value)`（WS 仅在线投递，重连补发初始值）。
  - 效果：托盘未读 == 网页消息页角标 `filteredUnReadCount`，有未读才闪、已读即停，实时同步。通知弹窗列表仍由 SYNC_UNREAD → `nc-unread` 提供（不受影响）。
