# 2026-08-07

## 设置窗口两处交互改动
1. **关于-主页地址「应用」按钮**：`src/settings-window.html` 的 about 面板 `主页地址` 行新增 `应用` 按钮（`.mp-apply` 蓝色样式）。`renderAbout()` 抽出 `validateMainPageUrl()` 复用于输入校验与按钮；点击「应用」→ 校验 + `save({mainPageUrl})` + `api.applyMainPage(url)`（新增 IPC `navigate-mainpage` in main.js）。主进程 handler 把 mainPageUrl 写入 settingsStore，若 mainPageWindow 存在则 `loadURL` 并 show+focus 即时刷新，不存在则 `openMainPage()` 主动打开。
2. **诊断测试移到左下独立菜单**：从「通用」面板移除诊断测试行；左侧 nav 底部新增 `🧪 诊断测试` 入口（`.nav-item.nav-diag`，`margin-top:auto` + 顶部分隔线），`data-action="diagnostics"`，点击直接 `api.openDiagnostics()`，不切换右侧面板（nav 点击处理逻辑据此分支）。

### 涉及文件
- `src/settings-window.html`（nav / 通用面板 / about 面板 / CSS / 脚本）
- `src/preload.js`：新增 `applyMainPage: (url)=>ipcRenderer.invoke('navigate-mainpage', url)`
- `main.js`：新增 `ipcMain.handle('navigate-mainpage', ...)`

### 注意
- settings-window.html 由 `settingsWindow.loadFile` 直接加载，无需构建步骤，下次启动即生效；main.js 改动需重启应用。

## 启动默认打开主页面窗口
- `main.js` 的 `app.whenReady().then(...)` 流程中，在 `notificationCenter.preCreate()` 之后、`startHttpServer(...)` 之前新增 `openMainPage()` 调用。
- 之前主页面仅在点击托盘时由 `tray.on('click')` 触发打开；现在程序启动即创建并加载主页面窗口（首次加载完成后自动 show+focus）。
- 托盘点击的 IM 式切换语义（可见聚焦则隐藏）保持不变。
