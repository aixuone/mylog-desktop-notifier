## macOS 关闭后再点托盘唤不回的修复（退出"纯托盘"模式）
- 根因：原代码 `app.dock.hide()` 让 app 隐藏在 macOS Dock 外，纯托盘模式下 `mainPageWindow.show() + focus()` 不会被系统激活到前台，关闭后再点托盘窗口已 hide 但 show 后失焦看不见。
- 5 处修改 main.js：
  1. 删 `app.dock.hide()`（1358 行注释保留但不再隐藏 Dock）。app 正常出现在 macOS Dock / Windows 任务栏。
  2. `window-all-closed` 改为按 `isQuitting` 决定是否 `app.quit()`（1445-1451）。所有窗口关闭仍驻留，仅在主动退出（菜单「退出」/Cmd+Q）才真退。
  3. 托盘 click 由 `openMainPage()` 改为 `toggleMainPage()` + `process.platform==='darwin' && app.focus({steal:true})` 兜底（1756-1761）。
  4. `toggleMainPage()`：destroyed 分支和 show 分支都加 macOS `app.focus({steal:true})` 兜底（1495-1509）。
  5. `openMainPage()` 窗口已存在的 show 分支加 macOS `app.focus({steal:true})` 兜底（1559-1565）。
- Windows 端无任何行为变化（`app.dock` 在 Windows 是 undefined，删除无影响；`app.focus` 仅在 darwin 分支执行）。
- 保留 `mainPageWindow.on('close')` 的 `preventDefault + hide()` 不动（钉钉/微信行为），HTML5 video / WebRTC / 表单状态保留在 renderer 进程内存里。
- 验证：`node --check main.js` 通过。
