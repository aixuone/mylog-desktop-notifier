## 通知点击深链只跳消息页不打开会话（11:55 修复）
- 现象：点消息提示窗（通知中心）里某会话 → 只切到 /message，不默认选中对应会话。
- 根因：桌面 `focusConversation` 走 `focusMainWindow(url)` = `history.pushState('/message?conv=xxx') + dispatch popstate`（SPA 内导航，**非整页刷新**）；web 端深链消费原只在 layout.vue `onMounted` 读一次 `window.location.search` → SPA 运行时点击永远不会重新执行 → 只路由跳转、无会话选中。web `onMessage` 也从不消费桌面定向发的 `FOCUS_CONVERSATION`（无接收方，但 URL 通道已够）。
- 修复（layout.vue）：新增 `openConvDeepLink(convId)`（isConnected 守卫 + 未连接时 watch once isConnected）+ `watch(() => route.query.conv, ..., { immediate:true })`——运行中 SPA 导航命中即 `setActiveConversation(conv)` + push('/message')；消费后 `router.replace` 删除 conv query（防自触发/污染历史/支持重复点击同一会话）。删除 onMounted 旧单次逻辑。
- 链路核实：preload `openConversation(cid,url)` → IPC `nc-open-conversation` → `focusConversation` → focusMainWindow+markRead；router 守卫不吞 conv query（仅会议路由特判）。
- 桌面端零改动；需 web 重新构建部署后生效。
