## 8/14 第三次迭代：字段大扩展（用户指令）
按需求新增四大能力，已 `node --check` 通过 + 复刻纯函数 `_rectest.js` 校验 yearly/每周多选/endMode(date|count)/单次时间范围 全部 PASS。

### 1. 重复周期自定义 + 结束条件
- `reminder` 重构：`type:'once'|'repeat'`；once 用 `onceStart`/`onceEnd`（单次可选单个时间或时间范围）。
- repeat：`repeatMode:'daily'|'weekly'|'monthly'|'yearly'`；weekly `weekdays` 多选；monthly `anchorDay`；yearly `anchorMonth+anchorDay`。
- 结束条件 `endMode:'never'|'date'|'count'`，date→`endDate`，count→`endCount`+`countFired`（运行时计数）。`reminderEnded` 统一判定终止；`getPendingReminders`/`reminderDayMatches` 均已纳入。
- **迁移**：旧 `repeat:'workday'`→`repeatMode:'weekly'`(weekdays 周一~五)；旧 `once`→`onceStart`。`normalizeReminder`=`migrateReminder`。
- 编辑弹窗：单次显示开始/结束(datetime-local)；周期显示时间+重复类型(每天/每周多选/每月N号/每年N月N日)+结束条件三选一。

### 2. 参与人（通讯录 + 拼音模糊搜索）
- 新增 `workbench-contacts` IPC（`main.js`）：读 `settingsStore.loadContacts()`（即 `contactsCache.json`，网页 SYNC_CONTACTS 缓存），用 `pinyin-pro`（新装依赖）算 `py`(全拼小写)+`initials`(首字母)，返回 `{id,name,avatar,py,initials}`。
- 编辑弹窗内「参与人」区：chips（头像+人名+×）+「＋添加」→ 通讯录浮层，按 name/py/initials 模糊匹配（支持 zhangsan / zs）。任务存 `participants:[{id,name,avatar}]`。卡片显示头像组。

### 3. 地点（手动输入 + 地图选点，合规）
- **地图合规**：按 geo-map-compliance-guard 规则，禁用 OSM/Leaflet；改用**腾讯地图 GL JS**（GL JS，GCJ-02）。因本应用是独立桌面端（非 WorkBuddy 代理运行时），用显式 Key 模式：`https://map.qq.com/api/gljs?v=1.exp&key=KEY&libraries=service`，Key 存本地 `settingsStore.mapKey`（新增 `workbench-set-mapkey` IPC，随 `workbench-load` 返回）。
- 编辑弹窗「地点」：手动输入地址 或「地图选点」→ 腾讯地图浮层（搜索模糊匹配结果列表 + 点击地图落点 + Geocoder 反查地址），保存 `{address,lat,lng}`（GCJ-02，仅本机）。无 Key 时浮层提示先填 Key，手动输入仍可用。
