# 2026-08-20 稳定版上线改动（desktop-notifier）

为发稳定版，按用户 9 条需求完成代码修改（均未打包验证，仅语法校验通过）：

1. **隐藏工作台入口（需求1）**：`main.js` `buildWindowMenu()` 移除「工作台」菜单项；`whenReady` 不再调用 `startReminderEngine()`（停后台系统通知弹窗）。工作台窗口仍可由快捷键呼出（需求2）。
2. **工作台快捷键 toggle（需求2）**：新增 `toggleWorkbenchWindow()`（显示↔隐藏），`registerWorkbenchHotkey()` 绑定之。
3. **消息时长默认 5s（需求3）**：`settingsStore.DEFAULTS.messageNotify.duration` 8→5，并加迁移（旧用户 duration===8 自动降 5）；`notificationCenter.resetIdle` fallback `||8`→`||5`。
4. **关于页三击显敏感信息（需求4）**：`settings-window.html` 加 `.secret-hidden`，主页地址块 + 设置文件行默认隐藏；`about-secret-title` 连点 3 下（1.5s 内）揭开。
5. **弹窗固定主屏右下角（需求5）**：`main.js` `getNcRect()` 由 `getActiveDisplay()`（光标屏）改为 `screen.getPrimaryDisplay()`（主屏）。诊断页文案同步"主屏"。
6. **诊断设备自检（需求6）**：`diagnostics.html` 新增「设备自检」卡片 + `runDeviceCheck()`：麦克风（getUserMedia+AnalyserNode 实时音量 RMS 峰值）、摄像头（预览）、扬声器（AudioContext 660Hz 测试音）。按 NotAllowed/NotFound/NotReadable/Overconstrained/TypeError 分类给「怎么处理」引导（扬声器没选对→设系统默认输出设备；设备没打开/被占用→关占用程序；无设备→插设备/驱动；不支持→重装客户端）。
7. **修复聚焦测试（需求7）**：`diagnostics.html` R7 判定由 `(webConnected?focus:external)` 改为以 `appConnected` 为准（预期 `appFocus`/`none`），与实际 `diagFocusTest` 返回一致。
8. **网页菜单刷新（需求8）**：`main.js` `buildWindowMenu()` 最右加「刷新」项 → `reloadMainPage()`（`mainPageWindow.reload()`）。
9. **自动更新（需求9）**：仅给方案（见回复），未改代码——建议 electron-updater generic provider 指向 COS 目录，放 latest.yml+exe，配 CORS/公共读。

校验：`node --check` 通过 main.js / settingsStore.js / notificationCenter.js；提取两 HTML 内联 JS 校验通过。

**修正（复核）**：复检发现 `main.js` 的 `getNcRect()` 此前实际仍用 `getActiveDisplay()`（光标屏跟随），需求5未真正落地。现已改为 `screen.getPrimaryDisplay()`（主屏右下角），`node --check` 通过。诊断页 ncRect 展示随之与主屏一致。

## 第二轮反馈处理（用户评审改动清单）

- **需求4微调**：关于页移除"连点3下"提示——删 `about-secret-title` 的 `title` 属性、`#secret-tip` 可见提示文案，及 `setupSecretReveal` 中死引用。敏感信息隐藏更彻底。
- **需求7修复（离线/被踢模拟异常）**：根因 `diagSysAlertTest()` 自校验时 push 完 offline/kick 立即 `dismissSysAlert` + `hideWindow()`，导致手工"模拟常驻通知"按钮只闪一下、用户根本看不到常驻卡片。拆分为 `diagSysAlertSimulate()`（只 push、保持可见）+ `diagSysAlertClear()`；手工按钮改调 simulate，自动测试 R8 仍用原 test；main.js 新增 `diag:sysalert-simulate`/`diag:sysalert-clear` IPC，preload 暴露，诊断页⑦加"清除模拟"按钮。
- **额外1（下载不弹新窗）**：`mainPageWindow.webContents.setWindowOpenHandler` 拦截——download/saveToDisk → `downloadURL()`，_blank 等 → `shell.openExternal`；session `will-download` 落盘到用户下载目录。
- **额外2（全屏隐藏菜单）**：`mainPageWindow` 监听 `enter/leave-full-screen` 与 `enter/leave-html-full-screen`，全屏时 `setMenuBarVisibility(false)`。
- **需求5（双屏看不到弹窗）**：主屏改动未解决"个别用户双屏都看不到"；偏环境性（Windows 前台锁使 focusable:false 窗无法置顶、独占全屏应用压过 alwaysOnTop、hiddenByUser 偶发卡住）。待用户确认是否加 `showWindow` 加固重试 + 诊断可见性自测。
- **需求1/2 git 分支**：用户要求工作台迁到独立分支、本分支停开发；当前分支 main 已 release 工作台且有未提交 workbench WIP。分支策略待用户拍板。
