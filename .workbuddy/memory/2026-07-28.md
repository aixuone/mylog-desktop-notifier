## 修复：electron-builder 打 Mac 包报 ENOENT（.exe 扩展名写死）
- 文件：`package.json`（build 配置）
- 报错场景：GitHub Actions 跑 `npx electron-builder --mac`，x64/arm64 两个 DMG 都报
  `ENOENT ... open '.../我的日志_桌面通知 安装包 1.1.0.exe'`。
- 根因：顶层 `build.artifactName` 写死 `${productName} 安装包 ${version}.exe`；electron-builder 生成 blockmap 时按顶层模板用 `.exe` 找 DMG 产物（实际是 `.dmg`），找不到即 ENOENT。mac 段虽配了 `.dmg`，但 blockmap 这一环实际取的是顶层模板。
- 修复：两层 `artifactName` 都改为 `${productName} 安装包 ${version}.${ext}`，`${ext}` 按目标自动展开（dmg→.dmg、nsis→.exe）。
- 校验：`node -e require('./package.json')` JSON 合法，两处 artifactName 均含 `${ext}`。
- 注意：日志里 "skipped macOS notarization" 是**警告非报错**——未配置 Apple 公证凭证（APPLE_ID/APPLE_APP_SPECIFIC_PASSWORD/APPLE_TEAM_ID）。如需用户免 Gatekeeper 拦截安装，需在 Actions secrets 加这三个变量并配 notarize；当前不影响打包成功。另 "Implicit publishing triggered by CI detection" 仅为提示，可在命令加 `--publish never` 显式关闭。
- 后续：本地改完需 commit & push，Actions 重新跑才会生效。
