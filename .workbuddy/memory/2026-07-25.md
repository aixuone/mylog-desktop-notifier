- 修正：`renderRingtone` 恢复 SCENES 循环，为每场景渲染 `RingtonePicker`（仅改 `st.ringtones[场景].file`），不再渲染 `enabled` 开关。`enabled` 由通用模式 + 总开关统一控制；选择器 `onChange` 顺带把 `enabled` 置 true（已无独立开关，交互即代表启用）。

## 第四轮修正（当晚稍后）：托盘头像仍未显示 + 菜单标题/退出图标/联动

### 问题 1：托盘在线用户头像仍不显示
- 根因：① 头像只存在易失的 `connectedClients` 条目 `localIconPath` 里，WS 重连 reclaim 时旧 key 被删、图标丢失；② 离线/主用户分支（`else if currentUser.userName`）从不设置 `MenuItem.icon`，只有在线分支设。
- 修正：新增 `userIconCache`（Map，按 userId 缓存头像路径，抗重连抖动）；`storeClientIcon(wsClient, iconPath)` 统一落盘（写连接项 + 写 userId 缓存 + 触发 updateTrayMenu + 同步 legacy `localUserIconPath`）；`downloadUserIconForClient` 成功与 `data:image` 内联两种情况都走 `storeClientIcon`。`updateTrayMenu` 在线分支取 `userIconCache.get(userId) || u.localIconPath`，离线分支取 `localUserIconPath`；新增 `loadMenuIcon(p)` 防御性加载（空图/损坏格式返回 null，绝不抛异常）。
- 兼容性：`downloadUserIconForClient` 额外支持 `data:image` base64 内联头像直接落盘（无需网络）。

### 问题 2：版本号位置
- 标题改为第一行 `我的日志（v${version}）`（version 实际取 package.json = 1.1.0，用户举例写的 1.1.1 是格式示例）；删除原先独立的 `v${version}` 菜单行。

### 问题 3：退出图标
- 删除彩色 emoji 🚪，改为**零依赖手写的单色电源(关机)图标**：`encodePNG`（自实现 PNG 编码，仅用 zlib）+ `makeShutdownIcon`（绘制开口圆环+顶部竖线，单色 90,90,90）+ `getShutdownIcon()` 懒加载 16×16。
- 退出项 `label:'退出'` + `icon:shutdownIcon`，图标位于左侧列，与「开机自启」checkbox 对勾左列对齐。
- 约束：运行时依赖只有 `ws`（jimp 是 devDependency，打包后不可用），故图标必须零依赖生成，不能用 jimp。

### 问题 4：铃声总开关与通用模式联动
- 新增 `syncMasterSwitch()`：当 `notifyMode==='silent' || 'dnd'` 时，强制总开关关 + `disabled`（灰化、不可改）；其余模式恢复可切换并反映 `S.ringtoneEnabled`（不改动存储值，切回正常时保留用户原偏好）。
- 调用点：`renderGeneral` 模式切换后 + `renderRingtone` 渲染末尾。
- 场景个性化铃声选择器（`renderRingtone` 内 SCENES 循环）不受影响，始终可改。
- 新增 CSS：`.switch.disabled`（opacity 0.4 / cursor not-allowed）、`.switch.sound.disabled`（强制灰底 #D9D7D2 + 🔇）。
